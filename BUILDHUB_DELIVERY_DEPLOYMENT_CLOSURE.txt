    Run if [ -n "" ] && [ -n "" ]; then

Both staging secrets are empty, so the three downstream jobs -

    Gate on the full CI suite     skipped
    Build and publish the image   skipped
    Migrate and release           skipped

All 112 "success" conclusions on that workflow are the gate job alone reporting
configured=false.

Deployment happens through render.yaml instead:

    branch: main
    autoDeploy: true

deploy-staging.yml means NOTHING about whether a deploy occurred.
