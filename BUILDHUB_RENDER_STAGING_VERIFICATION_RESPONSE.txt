9. DEFECTS FOUND AND FIXED THIS SESSION
================================================================================

  1. GATE ORIGIN-CLASSIFICATION BUG (mine, found and fixed)
     The gate flagged a Google Fonts failure that was not real. Chromium's
     console message for a blocked font carries no URL, so my third-party
     classifier could not tell whose request failed and blamed the app.
     Fixed by classifying failures by request ORIGIN via page.on('requestfailed')
     instead of by console text. A third-party CDN failing is now correctly
     attributed to the third party.

  2. INCORRECT TEST ASSERTION (mine, found and fixed)
     One of my own new tests grepped ci.yml for the string "vitest", but CI
     invokes "pnpm run test". The assertion would have passed for the wrong
     reason and would have gone silent if the chain broke. Corrected to assert
     the whole invocation chain.

Both were defects in my verification apparatus rather than in BuildHub. I am
listing them because a gate that lies is more dangerous than no gate, and you
should know I audited mine.

No new BuildHub product defects were found this session - because no new
BuildHub surface was exercised. The 163 browser checks re-confirmed the fixes
from earlier slices; they did not reach untested ground.
