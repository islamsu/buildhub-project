2. THE FAILURE, CONFIRMED FROM THE RUN LOGS
================================================================================

Run 32478659001 died in "Install Playwright and its browser", before the smoke
test or any of the 22 points executed. Verbatim from the job log:

    npm error code ERESOLVE
    npm error ERESOLVE unable to resolve dependency tree
    npm error While resolving: buildhub@1.0.0
    npm error Found: vite@7.3.6
    npm error node_modules/vite
    npm error   dev vite@"^7.1.7" from the root project
    npm error
    npm error Could not resolve dependency:
    npm error peer vite@"^4.0.0 || ^5.0.0" from @builder.io/vite-plugin-jsx-loc@0.1.1
    npm error   dev @builder.io/vite-plugin-jsx-loc@"^0.1.1" from the root project
    ##[error]Process completed with exit code 1.

WHY IT HAPPENS: the install runs inside the repo checkout, so npm resolves
BuildHub's whole dependency tree before it can add anything. That tree carries
a genuine peer conflict - @builder.io/vite-plugin-jsx-loc@0.1.1 declares a peer
of vite ^4 || ^5 while the project is on vite 7 - and npm's default strict peer
resolution aborts before Playwright is ever fetched.

Two earlier steps DID succeed, which is worth noting: "Resolve the target"
accepted the URL you passed (with its trailing slash) and the job was running
within 7 seconds of dispatch.
