4. DEFECTS FOUND AND FIXED THAT NOBODY HAD REPORTED
--------------------------------------------------------------------------------

  These were found by building guards and probes, not by a bug report. Listed
  because they indicate the class of problem the codebase had.

  - The referral engine could never fire (no writer for campaignId).
  - The Super Admin console was unreachable except by typing a URL.
  - Disputes were write-only; the notification link resolved to nothing.
  - Three disagreeing product-category vocabularies; one pair shared no values,
    so a whole browse path could never return a product.
  - Six silent list truncations (users, disputes, products, projects,
    placements, vendorNameChanges) each paired with browser-side search.
  - Unescaped LIKE patterns in six places, including one predating this work:
    an administrator searching the enquiry list for "%" matched every row.
  - A referral reward silently destroyed an unrelated administrator grant.
  - Referral placements were booked on a surface no reader queries, so the
    reward was invisible.
  - admin.disputes read every user on the platform into memory to resolve two
    names per row.
